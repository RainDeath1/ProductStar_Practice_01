Credit Telegram Bot

Описание проекта

Credit Telegram Bot - это telegram-бот для расчета графика погашения кредита

Бот позволяет пользователю расчитать крдит с использованием аннуитетной или дифференцированной схемы платежей,
просмотреть историю своих запросов, а менеджеру - получить статистику по использованию бота.

Проект разработан на языке Java с использованием библиотеки TelegramBots

Возможности

Для пользователя

-Расчет кредита
-Поддержка аннуитетных платежей
-Поддержка дифференцированных платежей
-Просмотр графика платежей
-История выполненных расчетов
-Проверка корректности вводимых данных

Для менеджера

-Авторизация
-Просмотр аналитики
-Кол-во выполненных расчетов
-Средняя сумма кредита
-Самый популярный тип платежа

Используемые технологии

Команды бота

/start       Начало работы
/calculate   Новый расчет кредита
/history     История расчетов
/login       Авторизация менеджера
/manager     Просмотр аналитики


Алгоритм расчета

Алгоритм расчета

После запуска команды /calculate бот последовательно запрашивает:

сумму кредита;
срок кредита;
процентную ставку;
тип платежа.

После ввода данных рассчитывается полный график погашения кредита.

Проверка данных

Во время ввода данных выполняется валидация:

сумма кредита должна быть больше 0;
сумма ограничена максимальным значением;
срок кредита — от 1 до 600 месяцев;
процентная ставка — от 0.01 до 100%;
проверяется корректность числового ввода.
Авторизация менеджера

Данные менеджера хранятся в файле .env.

После успешной авторизации становятся доступны функции просмотра аналитики.

Конфигурация

Создайте файл .env в корне проекта.

Пример:

BOT_NAME=YourBotName
BOT_TOKEN=YOUR_BOT_TOKEN

MANAGER_LOGIN=manager
MANAGER_PASSWORD=12345
Запуск проекта

Склонировать проект:

git clone <repository-url>

Перейти в каталог проекта:

cd telegram_bot

Запустить:

./gradlew run

или запустить класс Main.

Тестирование

Для запуска всех тестов:

./gradlew test

Используются тесты JUnit 5.
